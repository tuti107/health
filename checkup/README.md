# 健康診断記録

健康診断・血液検査などの結果をテキストデータ化して蓄積するセクション。

## 運用

1. 診断結果票の写真をGoogleドライブの `10_健康診断（写真アップロード用）` フォルダにアップロード
2. Claudeが写真を読み取り、`checkup/YYYY-MM-DD_検査名.md` としてテキストデータ化
3. 経年変化を追跡できるよう、主要項目は下記の推移表にも転記
