# 健康Wiki（ホーム）

## 目的

このWikiは、土田さんの健康に関するすべてのデータを一元化し、以下を実現するためのものです。

1. **ランニングイベントでのパフォーマンス向上**（次目標：札幌マラソン 10km）
2. **年齢による各種体調不良の回避**（男性更年期障害／LOH症候群の予防を含む）
3. 健康データの**可視化**と、データに基づく**健康への提言**の随時更新

## データソースと運用フロー

| データ | 取得方法 | 格納先 |
| --- | --- | --- |
| ランニング記録 | iPhoneフィットネスアプリのスクリーンショット | Googleドライブ `20_フィットネススクショ` → テキスト化して `running/` |
| 健康診断結果 | 診断結果票の写真 | Googleドライブ `10_健康診断` → テキスト化して `checkup/` |
